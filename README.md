# 📝 Text Summarizer using FastAPI and Hugging Face

A web-based Text Summarization application built with Python, FastAPI, and Hugging Face Transformers. 
This project takes long text as input and generates a concise summary using the `t5-small` transformer model.



## 🚀 Live Demo

https://text-summarizer-3o6z.onrender.com



## 📌 Features

- Summarizes long text into short and meaningful summaries
- Built using Hugging Face `t5-small` model
- FastAPI backend for REST API and web serving
- Simple and clean HTML/CSS frontend
- Deployable on Render
- Responsive UI
